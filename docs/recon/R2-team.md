## Почему фильтруем по id, а не по имени

На HLTV регулярно встречаются производные и одноимённые названия: у этой
организации в истории матчей рядом идут `FORZE Reload`, а в сцене — `forZe`
(другая, основная команда, другой id). Плюс общая практика сайта — префикс
`ex-` при распаде состава (`ex-RUSTEC`, `ex-RUBY`, `ex-Zero Tenacity`
встречались в расписании в день разведки). Имя команды может смениться, id — нет.

**Вывод: все фильтры в сервисе строятся по `team_id == 12857`.** Имя хранится
только для рендера сообщений и обновляется из последнего наблюдения.

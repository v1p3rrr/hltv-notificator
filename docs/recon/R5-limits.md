# R5 — Ограничения источника

Дата наблюдения: 2026-08-29. Источник: https://www.hltv.org/robots.txt

Это не юридическая экспертиза, а фиксация наблюдаемого, чтобы решения
принимались осознанно.

## robots.txt — что запрещено (выдержка по релевантным разделам)

```
User-agent: *
Disallow: /matches?*
Disallow: /results?*startDate*   (и ещё ~8 фильтров /results?*)
Disallow: /stats?*  /stats*?*    (широкий набор фильтров)
Disallow: /forums/*
Disallow: /blog/*
Disallow: /download/demo*
Disallow: /legacystats/*
Disallow: /fantasy/*/league/*?*
Disallow: /transfers?*
Disallow: /events/archive  /events/archive?*
Disallow: /search/?*offset*  /search/?*variant*
Disallow: /valve-ranking/teams/details/*
Disallow: /skins/*?<фильтры>
Allow: /ads.txt
Sitemap: https://www.hltv.org/sitemap_index.xml
```

## Что это значит для сервиса

| Страница | Статус | Используем? |
|---|---|---|
| `/team/12857/forze-reload` | не запрещена | **да** — основной источник расписания |
| `/matches/<id>/<slug>` | не запрещена | **да** — состояние матча, счёт по картам |
| `/matches` (без query) | не запрещена | нет необходимости |
| `/matches?...` (фильтры, в т.ч. по команде) | **запрещена** | **нет** |
| `/results?...` (фильтры) | **запрещена** | нет |
| `/stats...` (фильтры) | **запрещена** | нет |

Соблазнительный `/matches?team=12857` даёт готовую выборку — и он запрещён.
Поэтому расписание берём со страницы команды, где ровно те же данные лежат в
разрешённой зоне.

Про `scorebot-lb.hltv.org` в robots.txt сайта ничего нет; это отдельный хост,
своего robots.txt у него не наблюдалось. Он обслуживает тот же виджет, который
работает у обычного посетителя с открытой вкладкой.

## Рекомендация по частотам

Цель — быть неотличимым от пользователя, который держит вкладку открытой.

| Режим | Интервал |
|---|---|
| Фон (нет матчей в ближайшие 30 мин) | 30 мин |
| Предматчевый (за 30 мин до старта) | 3 мин |
| Активный (матч идёт, живого фида нет) | 60 сек |
| Активный при работающем scorebot | 5 мин |

Потолок, зашитый в код: **не чаще 1 запроса в 30 секунд** глобально. Запросы
строго последовательные (один в полёте), джиттер ±20%, никаких параллельных
пулов и никакой ротации прокси. Одно websocket-соединение на активный матч.

Сутки без матчей — порядка 48 запросов. Сутки с одним BO3 — порядка 150.
